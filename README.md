# NiveshRakshak AI

**Team CLAIMMER — Sangyan Hackathon, IIT (BHU)**

NiveshRakshak AI is an investor-safety copilot concept for retail investors. This frontend MVP demonstrates:

- Investment message risk analysis
- Explainable safety scoring
- Potential red-flag detection
- Screenshot upload UI
- Beginner-friendly financial explanations
- Investor scam-awareness simulator
- Product architecture and technology stack

## Run locally

No build system is required for this MVP.

1. Extract the ZIP.
2. Open `index.html` in a browser.

For a local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Important

This is a hackathon MVP/demo. It does not provide investment advice and does not definitively classify a message as fraud. The demo uses browser-side pattern matching; production deployment should connect a secure backend, OCR/document processing and a properly evaluated AI model.
